GitHubリポジトリ`haihirosu/family-tree`に、汎用的な家系図エディターVer.1を実装してください。

最初に最新のリポジトリ、適用されるAGENTS.md、および以下を読んでください。

1. `docs/family-tree-v1-detailed-design.md`（確定済みの詳細仕様・受入条件）
2. `v1/README.md`（実装先）

本タスクが渡された時点で実装開始の指示です。仕様承認を取り直す必要はありません。画面寸法・配色・関数名等は仕様を保つ範囲で判断して進めてください。

## 作業範囲

- アプリは**リポジトリ直下の`v1/`**に作成し、エントリーポイントを`v1/index.html`にしてください。
- HTML/CSS/JavaScriptを使用し、jQueryは固定バージョンをルート`vendor/`へ同梱してください。外部CDNに依存させないでください。
- GitHub Pagesのプロジェクトパス`/family-tree/v1/`で動く相対パスにしてください。
- サンプルはルート`samples/sample_family.json`へ架空データで作成してください。少なくとも通常の3世代、片親、再婚、独立した複数家系、NULLと部分日付を含めてください。
- 既存`test/`や他バージョンのディレクトリは変更しないでください。自作共通化は必要が生じた時だけ`shared/`を使ってください。
- 実在する人物・家系の情報を、ソース、サンプル、テスト、画面確認用データに入れないでください。

## 必ず守るデータ・操作仕様

- 単一JSONに`schema_version`、`auto_increment`、`persons`、`families`、`family_children`を持たせてください。
- 3テーブルのIDカウンターは独立し、次回IDを保持し、削除済みIDを再利用しないでください。
- 人物の新規作成時はメモリ上の仮人物とし、配置が成功した時に正式IDを発行してpersonsへ入れてください。未配置人物はJSONへ書き出さないでください。
- 孤立した正式人物も有効です。`is_placed`、座標、世代を保存データに追加しないでください。
- 日付は部分日付対応の整数`YYYYMMDD`。`is_alive`はtrue/false/nullです。
- 同じfamilyへの重複childと、順不同で同じ2人をパートナーとする重複familyを防いでください。
- 親子の「接続」は既存関係を残して追加してください。
- 親子の「移動」は、対象familyに未接続なら、既存親関係0件で新規作成、1件でそのレコード更新、2件以上で旧関係を全て残して新規追加してください。
- 同じfamilyへの移動は順序変更だけです。兄弟順はsort_orderの1始まり連番で、並べ替え・削除時に再採番してください。
- 人物削除はパートナー参照をSET NULL、本人をchildとする親子レコードをCASCADE削除。family削除はその親子レコードだけCASCADE削除し、人物を残してください。
- 複合操作は検証成功後に一括反映し、失敗時はIDカウンターを含めて無変更にしてください。

## 描画とUI

- 人物1人につきカード1枚で、関係から自動配置してください。複数の独立家系と、接続による家系の結合に対応してください。
- パートナーは横、親子は縦。兄弟順を反映し、編集後は原則全体再描画、倍率と表示位置を可能な範囲で保持してください。
- PC・スマートフォン共通で、カード選択→操作選択→相手または配置候補のタップを基本にしてください。
- 候補一覧からも配置・接続できるようにし、パン・ズーム・ピンチ・名簿切替を実装してください。
- 人物情報は家系図・名簿の両方から編集可能にしてください。
- 固定UIはja/en/viの辞書方式。利用者が入力した名前・地名等を翻訳しないでください。
- 世代・兄弟順が両立しない特殊例外は、必要になってから検討する方針です。家族別分割表示、人物カードの再掲、特殊な自動修復を先回りして実装しないでください。描画の例外を解決するためにデータを改変しないでください。

## 読込・保存・プライバシー

- 起動時は`samples/sample_family.json`を自動取得。アップロードはデータ検証成功後に全置換してください。
- 読込失敗では既存データを保持してください。サンプル取得失敗時には再試行・ファイル選択・空で開始を用意してください。
- 保存はJSONダウンロード。破棄確認、ページ終了警告、自動保存は不要です。
- localStorage/IndexedDB等への永続保存、外部への家系データ送信、暗号化は実装しないでください。
- ユーザー入力をHTMLとして実行せず、テキストとして表示してください。
