# Ver.1 実装・検証記録

2026-11-25。実装依頼の再実行により、途中の作業ファイルから実装を再開した。

## 実装

- データモデル、限定正規化、参照・重複・部分日付・生死・祖先循環検証、原子的コマンド。
- 関係からの決定的な世代配置・兄弟順、HTMLカードとSVG線、空家族・複数家系。
- 仮人物、人物編集、移動0/1/2件、親子・パートナー接続、家族・親子属性編集、個別解除・削除。
- 名簿検索、配置候補一覧、パン・ズーム・ピンチ、再描画時の人物アンカー保持。
- UTF-8 JSON読込、ダウンロード、連続読込トークン、架空サンプル、日本語・英語・ベトナム語。
- jQuery 3.7.1をMITライセンスとともに固定同梱。ビルド・CDN不要。

操作の統括はapp.js、汎用フォーム・シート部品はui.js、保存対象の操作はcommands.jsに分離した。仕様書のモジュール名・分割は案であり、独立したinteraction.jsは作成していない。

## 実施済み

`npm test`で34件成功（Node.js v24.22.3）。移動0/1/2件、同一家族の並替え、既存関係を残す接続、削除連動、重複・自己関係・循環拒否、ID再利用防止、原子性、NULLと型、部分日付、JSON往復、不正UTF-8、未知文字列・フィールド、レイアウトの決定性・カード非重複・線のカード回避、描画条件競合、辞書キーとパラメーター、パンとタップの分離、ピンチ中点・再描画アンカーを検証した。

コード確認では、ネットワーク取得は同梱辞書と架空サンプルのみ。家系情報のサーバー送信・localStorage・IndexedDB・Service Worker・テレメトリーを導入していない。利用者文字列はtextContentで描画する。

### 性能の参考計測

Node.js v24.22.3、開発用Linux環境、架空の片親直系を1回計測。描画DOM生成時間は含まない。端末性能の保証には使わない。

| 人物数 | 検証 | レイアウト |
|---|---:|---:|
| 100 | 4.1 ms | 25.3 ms |
| 500 | 9.5 ms | 118.5 ms |
| 2,000 | 10.4 ms | 1,493.3 ms |

深い2,000世代はレイアウト計算だけでも約1.5秒かかる。最大件数・深い家系での操作応答には制約があり、実機で性能を評価する必要がある。
