# Family Tree Ver.1

エントリーポイント: [`index.html`](index.html)。日本語・英語・ベトナム語の固定UIに対応し、利用者が入力した内容はそのまま保持します。

## ローカル起動

リポジトリのルートで `npm start`（Node.js 20以降）を実行し、<http://127.0.0.1:8080/v1/>を開きます。ビルド・npm installは不要です。`python3 -m http.server 8080`も使用できます。

## 操作

- 人物追加 → フォーム保存 → 配置候補選択。配置を取り消しても仮人物は未配置欄に残り、配置成功時に正式IDを発行します。
- カードまたは名簿で人物を選ぶと、詳細・編集・移動・関係接続・削除ができます。人物の選択は家系図でも検索一覧でも行えます。
- 「移動」は親家族と兄弟順の変更です。他家族への移動時、親関係0件は新規、1件は既存関係を更新、2件以上は保持したまま追加します。同一家族なら順番だけ変えます。
- 「子を接続」「親家族へ接続」は既存関係を保持して追加します。パートナー枠の変更は関係管理で解除後、新しい接続を作ります。
- F番号の家族チップから婚姻状態、パートナー枠、子とその関係種別を編集できます。
- 背景ドラッグでパン、ホイール／2本指でズームします。拡大・縮小・全体表示ボタンも使えます。配置候補が小さい場合は「選択」の一覧を利用してください。
- 言語は右上の選択欄から切り替えられます。初期言語はブラウザー設定から判定します。

## 保存

「JSONを保存」で正式人物と関係をダウンロードします。未配置人物、表示位置、倍率、言語は保存しません。**再読込で編集内容は失われ、サンプルに戻ります。** 続きは保存したJSONを開いてください。読込成功時には現在の家系を置き換えます。確認ダイアログや終了警告はありません。

部分日付は年・月・日の分割入力です。不明な月・日は空欄にします。名前等が未入力でも人物を登録できます。性別・婚姻状態・親子種別の「その他」は自由入力です。

## 公開とプライバシー

GitHub Pagesでルートを配信した場合の入口は`/family-tree/v1/`です。`v1/`単体ではなく、`vendor/`と`samples/`も配信します。本実装はPages設定を変更しません。

家系JSONはブラウザーのメモリと利用者が保存したファイルにのみ保持します。永続ストレージ、Cookieへの家系保存、外部CDN、解析タグ、家系データのサーバー送信は使いません。初回のHTML・JS・辞書・架空サンプルの取得には通信します。

## 制約と確認状態

- 世代・兄弟順が両立しない特殊な関係の自動配置は対象外。データを書き換えて修復せず、名簿とJSON保存を保持します。
- 10 MiB、人物2,000、家族3,000、親子関係6,000件が上限です。最大規模でのスマートフォン性能は未検証です。
- 自由座標移動、写真、Undo/Redo、共同編集、クラウド保存、画像/PDF出力は対象外です。
- 自動テストは実施済み。ブラウザーの画面操作、幅360pxの実描画、iOS Safari／Android Chrome実機、通信の実測は未確認です。

リポジトリルートから`npm test`で検証します。[検証記録](../docs/v1-implementation-notes.md)と[確定仕様](../docs/family-tree-v1-detailed-design.md)を参照してください。
